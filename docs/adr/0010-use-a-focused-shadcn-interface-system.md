# Use a focused shadcn interface system

TournyHub uses Next.js, shadcn/ui with the Base UI foundation and Nova style, semantic Tailwind color tokens, Geist Sans, and one outline icon library. Setup and results screens use moderate-density tables, while Live Auction screens give the Active Player, current price, timer, and Bid action more space. Prices and timers use tabular numerals, motion remains restrained and interruptible, and color never carries state without a label or icon.
