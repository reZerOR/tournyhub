# Domain documents

TournyHub is a single-context project.

## Before making changes

- Read `CONTEXT.md` for canonical Auction terms before naming domain concepts.
- Read the relevant ADRs under `docs/adr/` before changing architecture, persistence, security, or Auction rules.
- Read `docs/product-spec.md` before changing user-visible Auction behavior.
- Use the glossary's preferred terms in code, tests, issues, and documentation.
- State any conflict with an existing ADR instead of silently replacing the decision.

If a referenced domain document does not exist, continue without creating an empty placeholder. Add domain documentation when a real term or durable decision needs it.
