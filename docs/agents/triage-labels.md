# Triage labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The specification is complete and an agent can implement it. |
| `ready-for-human` | `ready-for-human` | A human must perform the next step. |
| `wontfix` | `wontfix` | The project will not act on the issue. |

When a skill names a canonical role, use its local status from this table.
